## Validation on this branch

Local verification uses temporary files, fake clocks/executables, mocked AWS/GitHub calls and native Pulumi test mocks. No deployed target was contacted by these tests.

- Root and deployment-tool Go race tests and vet pass.
- Backend infrastructure Go race tests and vet pass with bounded compilation (`-p 1`, `GOMAXPROCS=1`, `GOGC=20`, `GOMEMLIMIT=512MiB`). Parallel compilation initially exceeded available memory; that was a compiler termination, not a passing test.
- Node admin/dashboard tests: 12 pass. Python helper tests: 9 pass.
- A real local Lambda build completes: 13 unique targets produce 21 archives. An unchanged rerun reuses all 13 target caches. All 21 archives pass the repository's validator.
- Workflow actionlint v1.7.7 passes with its external shellcheck integration disabled; YAML parsing and extracted Bash syntax checks also pass. Shell launcher syntax and fake-executable argument/exit-status tests pass.
- Windows amd64 and macOS arm64 cross-compilation pass. This is compilation evidence only. No native Windows console/ACL test was run; native deployment-tool tests have been added to the Windows verification job.

Shared `infra-index` Go race tests and vet also pass with the same bounded compiler settings. Do not infer runtime/cloud validation from these local checks.
