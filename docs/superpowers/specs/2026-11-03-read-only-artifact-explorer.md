Deployment publishes safe reporting.Report data to existing runtime table at id=ENV#<env>, sk=ARTIFACT_REPORT. Use bounded compressed snapshot (single item, <=256KiB compressed, <=512KiB JSON), reject oversize explicitly without truncation; local reports remain available if publication fails, warning shown. Preserve report timestamps and prevent older finished snapshots overwriting newer. Only application environment snapshots initially; public shared directory never exposes inventory. All signed-in authorized environment admins can view their own snapshot through protected GET endpoints; existing grants/client/origin boundaries retained. Return empty/unavailable states distinctly; no invented present/absent state.

On logout/env switch clear/revoke old content and discard stale responses. Do not load arbitrary report URLs. Safe typed model only, never raw Pulumi state, secrets or provider errors.
No AWS/cloud deployment/reset/state migration for validation. Tests/vet all four app Go modules GOWORK=off -mod=readonly, Node UI tests, relevant composer renderer/sort/filter tests and archive helper tests. Publish Composer + app PRs with exact public Composer commit pin; no local sibling replacements. Keep existing admin branch untouched.
